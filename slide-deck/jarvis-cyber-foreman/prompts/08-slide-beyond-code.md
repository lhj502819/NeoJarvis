## ⚠️ 语言要求（最高优先级 / HIGHEST PRIORITY）
- 画面上的所有文字必须是**简体中文汉字**，字形完整、清晰、正确，不得有缺笔画、错字或乱码。
- 允许保留的英文仅限产品名 **Jarvis**（正常大小写）。卡片标签也用中文。除此之外画面中**不得出现任何英文单词或字母**。
- 必须使用**中文字体**渲染，不要使用只适配拉丁字母的字体。

## Core Principles
- 杂志封面级高冲击视觉。禁止写实/照片元素。禁止页码、页脚、logo。
- 干净、只传达一个信息。

## 文字排版 Typography
- 标题：厚重的中文无衬线**粗黑体**，笔画粗壮，字号超大，纯白色。
- 卡片标签：清晰的中文黑体，字号小，纯白色。
- 严格按给定内容书写。

## STYLE_INSTRUCTIONS（视觉风格）
Design Aesthetic: 高冲击杂志编辑风；超大中文粗黑体标题，强烈对比，深色全出血背景，点缀色主导。
Background: 纯黑 (#0A0A0A)，无纹理，全出血。
Color Palette: 文字纯白 (#FFFFFF)；背景纯黑 (#0A0A0A)；Jarvis 核心 电蓝 (#3B82F6)；生活场景卡片用柔和的 紫/绿/橙 点缀。
Visual Elements: 中央一个 Jarvis 发光核心，向外辐射出多张生活场景图标卡片（像一个生活管理仪表盘）；文字为主视觉。
Density: 均衡——中心 + 3 张示例卡片。
Do: 中心辐射式布局、清晰图标、强对比。
Don't: 杂乱、褪色/浑浊颜色、纤细字体、页脚/logo、多余英文。
