- 这是**纯图形头像 Logo**，画面中**不得出现任何文字**：不要有 "Jarvis"、任何字母、数字、水印、色值或色名。

# 品牌语境
Jarvis 是一个 AI「主管/管家」产品——像钢铁侠的 Jarvis 那样，替主人管理一整支 AI 助手团队。这个 Logo 是 Jarvis 的人格化形象：一位沉稳、可靠、聪明的绅士管家。要有记忆点、有人味儿、值得信赖。

# 形象设定（人设，与扁平版共用同一个人）
- 一位中老年**中国男性绅士管家**（东亚 / 中国人面孔，黄种人肤色，黑色头发），半身/头肩像，正面或微侧。⚠️ 必须是中国人长相，不要西方/欧美面孔。
- 气质：沉稳、可靠、睿智、从容，带一丝温和的微笑，眼神专注可信。
- 发型：整洁的背头或利落短发，黑发、鬓角微白（成熟感）。
- 面部：典型东亚/中国人五官——黑色头发与眉毛、黄种人肤色；修剪整齐的短须或干净下巴，五官端正儒雅。
- 着装：经典管家装束——深色西装/燕尾服，白衬衫，领结或领带；可有一点点管家标志性细节（如胸前口袋巾），但整体简洁。
- 姿态：端庄、挺拔，管家式的得体。

# 渲染质感（本版）
- **手绘铅笔素描风（pencil / graphite sketch）**：可见的手绘线条、交叉排线阴影、纸张质感，有温度、有「人味儿」。
- 单色石墨灰调，或极淡的暖色纸底；以线条和明暗塑造体积。
- 精致的肖像素描感，像一幅用心画的炭笔/铅笔肖像；面部有辨识度但保留手绘笔触。
- 头像居中，占画面约 60-70%，四周留干净负空间（安全边距，避免圆形裁切切到脸）。

# 配色
- 独立风格。以石墨灰/铅笔单色为主，背景为干净的浅色纸底或中性留白。
- 整体优雅、有手作温度与品质感。
- 色值/色名仅作渲染参考，不要把任何色名或十六进制码画进图里。

# 构图约束
- 单一焦点：这位管家头像。
- 不要出现钢铁侠真人/商标形象——这是一个**原创的**绅士管家角色。
- 不要背景杂物、不要文字、不要 logo 边框，纯净头像 Logo。
