Create a 1:1 square brand mark: an extremely minimal gentleman-butler silhouette icon, designed for use at very small sizes (16–48px) on dark UI backgrounds.

## ⚠️ 文字要求（最高优先级）
- 这是**纯图形标记**，画面中**不得出现任何文字**：不要有 "Jarvis"、任何字母、数字、水印、色值或色名。
- 只画极简标记本身。

# 用途与设计目标（为什么需要这一版）
- 这是 Jarvis Logo 系统的**小尺寸副标**，与素描肖像版（大尺寸主标）配套。
- 使用场景：favicon（16×16 / 32×32）、App 顶栏图标、消息列表头像（28–48px）、社交平台小头像。
- 必须在 16px 极小尺寸下仍可辨认；细节越少越好，宁简勿繁。
- 背景必须适配深色 UI（App 主色 #12122a 深藏青），所以是**深底 + 亮线**的高对比方案，不要米白纸底。

# 形象设定（与主标共用同一个管家角色，但极度简化）
- 同一位中老年**中国男性绅士管家**的极简剪影/线条化版本：东亚面孔、黑发、沉稳。
- ⚠️ 必须是中国人长相，不要西方/欧美面孔。
- 只保留管家最辨识的几个符号：**背头短发 + 眉眼 + 领结**。其他五官、西装细节、口袋巾等全部省略。
- 不画写实肖像，而是**图标化的剪影/极简线条头像**。

# 渲染质感（本版）
- **极简线条图标（minimal line icon / glyph）**：粗细均匀的发光线条，几何化、对称、克制。
- 完全扁平，无阴影、无排线、无纸张质感、无手绘笔触。
- 圆形构图（适配圆形头像裁切）：头像剪影居中，圆形边框可选（一道细发光圆环）。
- 颜色策略：**深色背景 + 单一明亮电蓝色线条**，线条边缘有柔和辉光（glow / bloom），保证暗底上高对比、亮显示。
- 像一个高质量的 App 图标 / favicon，不是插画。

# 配色（适配深色 UI）
- 背景：纯黑到深藏青的深色（#0a0a1f 到 #12122a 范围），干净无纹理。可与 App 深色主题无缝融合。
- 主体线条：明亮**电蓝色**（electric blue），单一主色，最亮处接近白蓝高光。
- 不要米白、不要暖色纸底、不要木色。
- 色值/色名仅作渲染参考，**不要**把任何色名或十六进制码画进图里。

# 构图约束（小尺寸可读性优先）
- 圆形或正方形画布，头像剪影居中，占画面约 65–75%（略大于主标，因为细节少，可以更撑满）。
- 元素优先级（从重要到次要，必须按此顺序保留）：
  1. **背头短发轮廓**（一个简洁的拱形/带鬓角的发际线剪影）
  2. **两道眉 + 一对眼睛**（极简两点或短线，传达"注视、可信"）
  3. **领结**（位于下巴下方，一个小三角形或蝴蝶结剪影 —— 这是"管家"最强的符号锚点）
- 省略：鼻子、嘴、耳朵、西装、口袋巾、皱纹、阴影。
- 四周留干净负空间；如有圆形细环，环本身也要细，不要抢主体。

# 风格关键词（供渲染参考）
- minimal line icon, glyph, app icon, favicon, silhouette portrait, gentleman butler, bow tie, slicked-back hair, electric blue glow on dark navy, high contrast, flat, geometric, symmetric.

# 禁忌
- 不要出现钢铁侠真人/商标形象——这是**原创的**绅士管家角色。
- 不要背景杂物、不要文字、不要 logo 边框装饰（除可选的一道细发光圆环）。
- 不要照片写实、不要 3D、不要手绘笔触、不要排线阴影。

请使用 nano banana pro 生成上述极简标记，输出 1:1 正方形，建议高分辨率（如 1024x1024，便于后续缩放至 favicon 尺寸）。
